# AStockPilot

A股短线 1-5 天决策辅助 Web 工具。它只做数据分析、候选股筛选、回测和自选观察，不接券商、不自动下单、不承诺收益。

## 功能

- 盘后同步 A 股日线数据，默认使用 AKShare。
- 生成稳健短线候选：评分、观察价、止损、止盈、仓位建议和入选理由。
- 查看股票 K 线、成交量和最新信号。
- 运行简单回测，输出收益、胜率、最大回撤和交易明细。
- 管理自选观察列表。

## 启动

首次运行：

```powershell
cd E:\kai_project\AStockPilot
.\start-dev.ps1
```

打开：

- 前端：http://127.0.0.1:3008
- 后端：http://127.0.0.1:3018/api/health

进入页面后先点“同步数据”。默认同步 80 只股票近 2 年日线，第一次可能需要几分钟。

## 风险说明

本项目输出仅用于研究和复盘，不构成投资建议。A 股存在涨跌停、停牌、滑点、流动性、数据延迟和策略失效风险，实盘前必须人工复核。

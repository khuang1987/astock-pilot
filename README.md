# AStockPilot

A股短线 1-5 天决策辅助 Web 工具。它只做数据分析、候选股筛选、回测、自选观察和模拟交易，不接券商、不自动实盘下单、不承诺收益。

## 功能

- 盘后同步 A 股日线数据，优先使用 MooTDX，并保留东财、 新浪和 AKShare/BaoStock 兜底。
- 生成稳健短线候选：评分、观察价、止损、止盈、仓位建议和入选理由。
- 查看股票 K 线、成交量和最新信号。
- 运行简单回测，输出收益、胜率、最大回撤和交易明细。
- 管理自选观察列表。
- 使用 SQLite 持久化模拟账户、持仓、成交记录和日报。
- 默认每天 15:30 后自动同步数据并执行一次模拟调仓，可在“模拟交易”页暂停或调整时间。

## 启动

首次运行：

```powershell
cd E:\kai_project\AStockPilot
.\start-dev.ps1
```

打开：

- 正式入口：http://127.0.0.1:3009
- 健康检查：http://127.0.0.1:3009/api/health

进入页面后先点“同步数据”。默认同步 80 只股票近 2 年日线，第一次可能需要几分钟。

## 自动模拟交易

自动执行是模拟交易，不会连接券商账户。默认调仓频次为每个自然日检查一次；同一个最新交易日已经执行过时会跳过，避免每天频繁重复买卖。买入数量按可用现金、最大持仓数、单票资金上限、每日交易上限和 A 股 100 股整数手规则计算。

卖出规则按趋势/动量策略处理：止损和调仓卖出全仓执行；第一止盈默认卖出 50%，剩余仓位进入移动止损，从阶段最高价回撤默认 4% 时卖出。

## 数据源与策略路线

项目正在按 `a-stock-data` 方向升级数据层，但不会整包绑定外部项目作为核心逻辑。当前做法是新增独立适配器：先用 MooTDX 增强日线和实时行情稳定性，失败时继续回退到东财、 新浪等现有路径。

后续策略会增加“证据评分”：技术评分仍是主干，资金流、题材、估值、财务、公告和研报先作为决策依据与风险扣分，经过回测验证后再进入正式买卖规则。

## 风险说明

本项目输出仅用于研究和复盘，不构成投资建议。A 股存在涨跌停、停牌、滑点、流动性、数据延迟和策略失效风险，实盘前必须人工复核。

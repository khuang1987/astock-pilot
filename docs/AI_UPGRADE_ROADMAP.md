# AI 大模型升级路线

## 目标

让 AStockPilot 从“规则选股 + 模拟交易”升级为“规则策略 + AI 审核 + 每日复盘 + 参数建议”的辅助决策系统。

AI 不直接下单，不直接替代风控。AI 的作用是解释、审核、发现异常和提出可追踪的策略改进建议。

## 第一阶段：AI 候选审核

新增功能：

- 每天同步数据后，自动调用 AI 分析今日候选。
- 为每只候选输出：
  - 结论：观察 / 暂缓 / 剔除。
  - 风险等级：低 / 中 / 高。
  - 技术面解释。
  - 风控建议。
  - 是否适合进入模拟盘。

页面升级：

- 首页候选列表增加 AI 结论列。
- 个股详情页增加 AI 审核卡片。

后端升级：

- 新增 `ai_reviews` 表。
- 新增 `POST /api/ai/review-candidates`。
- 新增 `GET /api/ai/reviews?date=YYYY-MM-DD`。

## 第二阶段：AI 每日复盘

新增功能：

- 每天收盘后自动生成复盘。
- 复盘内容：
  - 今日候选整体表现。
  - 模拟交易盈亏归因。
  - 触发买入/卖出的原因。
  - 是否存在连续亏损或回撤扩大。
  - 次日策略注意事项。

页面升级：

- 新增“复盘”页。
- 按日期查看历史复盘。

后端升级：

- 新增 `daily_reports` 表。
- 新增 `POST /api/ai/daily-report`。
- 新增 `GET /api/reports/daily`。

## 第三阶段：策略参数建议

新增功能：

- AI 分析最近 N 天模拟交易和回测结果。
- 给出参数调整建议，例如：
  - 最低评分从 75 调到 78。
  - 单票上限从 10% 降到 8%。
  - 波动过滤更严格。
  - 暂停某类信号。

关键限制：

- AI 只能提出建议。
- 人工确认后才生成新策略版本。
- 每次调整必须写入 `strategy_versions`。

页面升级：

- 策略页增加“AI 建议”区。
- 增加“采纳并生成新版本”按钮。

## 第四阶段：数据交叉验证

新增功能：

- 多数据源比对：
  - MooTDX / 东方财富 / 新浪。
  - 腾讯行情和估值数据。
  - 后续可选接入同花顺、百度财经、Tushare Pro。
- 对最新价、成交量、涨跌幅做一致性检查。
- 对资金流、题材、公告、研报和财务数据做来源标记。

规则：

- 价格差超过阈值，标记异常。
- 成交量差超过阈值，标记异常。
- 数据过期时不生成新候选。
- 外部数据源异常时只降级展示和 AI 输入，不阻塞基础行情同步。

页面升级：

- 首页显示数据源状态。
- 个股详情显示数据一致性。

## 第四阶段补充：证据评分

AI 审核的输入需要从单一技术指标升级为多维证据包：

- 技术面：趋势突破、强势回调、放量启动、市场环境。
- 资金面：主力资金流、北向资金、龙虎榜和成交活跃度。
- 题材面：行业强弱、概念归属、强势题材归因。
- 基本面：PE/PB、市值、换手率、财报、F10、分红送转。
- 风险面：解禁、重大公告、异常新闻、停牌、数据不一致。

AI 只能解释证据和提示风险。证据评分进入买卖规则前，必须先写入日报和回测结果，人工确认后再进入 `strategy_versions`。

## 第五阶段：小时级候选观察

新增功能：

- 接入小时级行情。
- 对候选股做盘中或盘后小时级观察。
- 不做分钟级高频交易。

策略升级：

- 日线负责筛选股票池。
- 小时线负责观察走势和风险变化。
- AI 负责解释小时级走势是否支持原候选逻辑。

## 推荐自动任务

Windows 可用任务计划程序，或后续接入 APScheduler。

任务建议：

- 盘前：检查数据源、读取昨日候选和持仓风险。
- 盘中每小时：同步小时级行情，更新模拟盈亏和风险提示。
- 盘后：同步日线，生成候选，执行模拟盘，生成 AI 复盘。
- 每周：AI 汇总策略表现，提出版本调整建议。

## OpenAI 接入建议

建议使用后端统一封装 AI 服务，不让前端直接持有 API Key。

环境变量：

```env
OPENAI_API_KEY=
OPENAI_MODEL=
```

建议输出结构化 JSON：

```json
{
  "decision": "observe",
  "risk_level": "medium",
  "summary": "...",
  "reasons": ["..."],
  "warnings": ["..."],
  "suggested_actions": ["..."]
}
```

## 风险原则

- AI 结论不构成投资建议。
- 不根据 AI 文本直接实盘下单。
- 所有 AI 建议必须可追踪、可复盘、可撤销。

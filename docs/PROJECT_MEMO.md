# AStockPilot 项目备忘

## 当前定位

AStockPilot 是一个 A 股短线量化分析与模拟交易系统。当前版本只做研究、候选股筛选、模拟交易、仓位计算、策略验证和策略版本记录，不接券商、不自动实盘下单。

## 访问与端口

- 前端端口：`3008`
- 后端端口：`3018`
- 前端地址：`http://服务器IP:3008`
- 后端健康检查：`http://服务器IP:3018/api/health`
- 端口规则：前端端口 +10 为后端端口。

## 技术栈

- 后端：FastAPI + SQLite + Pandas + AKShare
- 前端：React + Vite + ECharts + lucide-react
- 数据库：`backend/data/astockpilot.db`
- 启动脚本：`start-dev.ps1`

## 当前页面

- 量化分析：首页，只显示候选列表，保留大标题和同步数据按钮。
- 自选股：维护自选列表，点击个股进入详情。
- 模拟交易：模拟账户、自动模拟买卖、持仓、成交记录。
- 仓位：根据资金、买入价、止损价计算建议股数。
- 策略：查看策略版本、参数和调整说明。
- 验证：用历史行情验证策略过去表现。
- 个股详情：点击候选或自选进入，查看 K 线、信号评分和入选理由。

## 当前候选策略 v1.0

数据周期：日线。

候选股来源：

1. 同步 A 股日线数据。
2. 对股票池逐只计算信号。
3. 符合条件的股票写入 `signals`。
4. 首页读取最新交易日的 `signals`，按评分排序展示。

核心规则：

- 至少 120 个交易日历史。
- 价格不低于 3 元。
- 成交额不低于 8000 万。
- 收盘价站上 MA20。
- MA5 强于 MA20。
- 20 日趋势为正。
- 成交量稳定或温和放大。
- 近期波动可控。
- 评分低于 62 不展示。

风控输出：

- 观察价：收盘价上方约 1%。
- 止损：约 -5% 或 MA20 附近。
- 止盈一档：约 +6%。
- 止盈二档：约 +10%。
- 高评分仓位：10%。
- 普通评分仓位：6%。

## 模拟交易逻辑

模拟交易不需要逐只手动买入。用户点击“执行一次自动模拟”后，系统会：

1. 读取今日候选股。
2. 按最低评分过滤。
3. 排除已有持仓。
4. 按可用现金、最大持仓、单票上限、每日交易上限自动买入。
5. 对已有持仓检查止损/止盈。
6. 触发条件时自动模拟卖出。
7. 记录持仓和成交记录。

当前模拟数据保存在浏览器 `localStorage`，不是后端持久化。

## 数据现状

当前默认数据源为 AKShare。适合盘后或低频策略。

注意：

- 周末和休市日不会有新交易日数据。
- 当前系统不追求分钟级行情。
- 下一阶段目标是小时级候选观察。

## 策略版本控制

后端已有 `strategy_versions` 表。

每次调整候选规则、参数阈值、数据周期或风控逻辑时，需要记录：

- 版本号。
- 生效状态。
- 数据周期。
- 参数 JSON。
- 调整说明。
- 创建时间。

建议版本规则：

- `v1.x`：日线策略迭代。
- `v2.x`：小时级策略接入。
- `v3.x`：AI 审核与策略建议闭环。

## AI 大模型升级方向

AI 不建议直接替代交易规则做买卖决策。更合理的职责是审核、解释、复盘和提出策略调整建议。

优先升级：

1. AI 候选股审核
   - 对今日候选逐只分析。
   - 判断是否建议观察、暂缓或剔除。
   - 输出理由和风险点。

2. AI 每日复盘
   - 收盘后总结候选股表现。
   - 对模拟交易盈亏进行归因。
   - 识别策略失效或市场环境变化。

3. 数据质量审核
   - 检查数据是否过期。
   - 检查行情源之间价格/成交量是否不一致。
   - 标记异常数据，避免策略误判。

4. 策略版本建议
   - AI 根据最近表现建议是否调整阈值。
   - 所有建议必须进入策略版本记录。
   - 人工确认后才生效。

5. 风险报告
   - 汇总当前持仓集中度。
   - 检查连续亏损、回撤、仓位过高。
   - 给出降仓或暂停模拟建议。

6. 小时级观察
   - 接入小时级行情后，AI 分析候选股日内走向。
   - 只做观察和审核，不做高频交易。

## 后续重要原则

- 先模拟，后实盘。
- AI 给建议，规则负责执行。
- 所有策略参数变更必须记录版本。
- 每天自动任务需要有日志、结果和失败提示。
- 不使用黑箱自动下单。
